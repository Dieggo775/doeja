# Roteiro de validação com a instituição

O enunciado pede **evidências de uso ou validação** e **métricas reais**. Este roteiro serve para coletar isso
numa visita de 1 h a 1 h 30 a uma instituição parceira. Tudo o que for anotado aqui vai para o relatório
(slides 2, 3, 5, 7 e 8 do modelo).

> Os dados das instituições que estão hoje no sistema são **fictícios** (demonstração). Nada do que está
> neste roteiro deve ser preenchido com dados inventados: as evidências precisam ter acontecido.

## Antes da visita

- [ ] Escolher a instituição (ONG, igreja, associação, ILPI/SAICA) em Taboão da Serra e marcar a visita.
- [ ] Levar a **Carta de Recomendação** (modelo da UniFECAF) para assinatura.
- [ ] Levar o **Termo de Cessão de Conteúdo e Uso de Imagem**, se for fotografar pessoas.
- [ ] Deixar o sistema no ar e criar a conta do responsável **na hora, junto com ele**.
- [ ] Imprimir ou abrir no celular o formulário de avaliação da comunidade (modelo da UniFECAF).
- [ ] Desligar o modo demonstração para a instituição real, ou cadastrar a instituição real além das fictícias.

## Parte 1 – Diagnóstico (antes de mostrar o sistema), cerca de 20 min

Anote as respostas com as palavras do entrevistado.

1. Quantas pessoas ou famílias a instituição atende por mês?
2. Que tipo de doação vocês mais recebem? E o que mais falta?
3. Como os doadores ficam sabendo do que vocês precisam hoje? (WhatsApp, Instagram, igreja, boca a boca...)
4. Com que frequência chega doação que vocês **não** precisam? O que fazem com ela?
5. Vocês registram o que entra? Onde? (caderno, planilha, nada)
6. Quanto tempo por semana alguém gasta respondendo "o que vocês estão precisando?" e "qual o horário?"
7. Já perderam doação porque o doador não achou o endereço ou chegou fora do horário?
8. O que tornaria a vida de vocês mais fácil nessa parte?

**Evidências:** foto da fachada, do estoque/depósito (sem rostos), do caderno/planilha atual, se autorizado.

## Parte 2 – Uso assistido do DoeJá, cerca de 30 min

Peça para o **responsável fazer**, você só orienta. Cronometre cada tarefa.

| # | Tarefa | Tempo | Precisou de ajuda? (sim/não) | Observações |
|---|---|---|---|---|
| 1 | Criar a conta de responsável | | | |
| 2 | Cadastrar o centro (endereço, horário, telefone, localizar no mapa) | | | |
| 3 | (Você, como admin) aprovar o cadastro | | | |
| 4 | Informar o que estão precisando, marcando o que é urgente | | | |
| 5 | Um voluntário/doador encontra o centro no mapa pelo bairro | | | |
| 6 | O doador registra uma doação | | | |
| 7 | O responsável vê a doação recebida e confirma | | | |

**Evidências:** prints de cada tela com os dados reais; foto do responsável usando o sistema (de costas ou mostrando a tela).

## Parte 3 – Avaliação, cerca de 10 min

Aplique o formulário de avaliação da comunidade (modelo UniFECAF) e acrescente:

1. De 1 a 5, quão fácil foi cadastrar o centro e as necessidades?
2. De 1 a 5, quanto o DoeJá ajudaria a receber o que vocês realmente precisam?
3. Vocês usariam no dia a dia? O que falta para usar?
4. Pode deixar um depoimento curto? (anotar textualmente e pedir autorização para usar o nome ou só o cargo)
